# Kristal-Microbiology

Kristal-Microbiology 1.0.0 is a static, source-backed Kristal v6 corpus centered on:

**microorganism ↔ environment**

Navigation axes: **metabolism · niche · growth · interactions**.

The axes are analytical views, not a one-way causal pipeline. Viruses are represented as acellular biological agents within the disciplinary scope of microbiology, not as cellular microorganisms.

Canonical state: `knowledge-base/corpus/microbiology.kristal-state.json`

Run `python knowledge-base/tools/validate.py` from the package root to validate schema, references, hashes, evidence coverage and manifest integrity.
