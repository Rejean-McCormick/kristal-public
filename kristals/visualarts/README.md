# Kristal-VisualArts v1.0.0

Kristal de référence sur les arts visuels comme système **œuvre → médium → technique → forme → sujet → contexte**.

Axes transversaux : **matérialité/conservation** et **provenance/interprétation**.

- 207 référents
- 488 assertions atomiques
- 9 sources de référence
- 282 assertions avec références documentaires explicites

Le corpus est statique, validé et lisible sans réseau. Les interprétations, attributions et classifications contestables sont modélisées comme assertions traçables plutôt que comme propriétés intrinsèques.
