# Frontière sémantique

Propriété : Demande origine-destination, réseau, mode, service, véhicule, flux, capacité, coût et temps.

Invariant métier préservé : Demande ≠ flux réalisé ; capacité ≠ débit observé ; mode ≠ véhicule ; réseau ≠ offre de service.

L’autorité des références externes reste celle des artefacts historiques ; aucun ownership des données externes ni des autres Kristals n’est créé.
