# Kristal Aging v1.0.0

Corpus statique de référence consacré aux **trajectoires dans le temps** : mécanismes du vieillissement, fonctions, réserves, résilience, déclin, fragilité, compensation et mesure.

Le Kristal est construit autour d’une ontologie de trajectoire plutôt que d’un catalogue de maladies. Il distingue explicitement **âge chronologique**, **vieillissement biologique**, **réserve**, **résilience**, **fragilité**, **fonction** et **compensation**.

Canonical artifact: `knowledge-base/corpus/aging.kristal-state.json` (Kristal Standard 6.0).

Validation: `python knowledge-base/tools/validate.py --write-report`.
Query: `python knowledge-base/tools/query.py --topic reserve_homeostasis`.
