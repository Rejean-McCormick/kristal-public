# Modèle natif

`native_model.kind = comparative_multilayer_tradition_practice_graph` (qualification descriptive de la forme existante, non conversion).

Modèle comparatif tradition/croyance/texte/transmission/pratique/institution/communauté non linéaire.

**Orientation principale :** tradition → croyance → texte/transmission → pratique → institution → communauté (orientation, pas théorie universelle).

**Invariants :** L’oralité et les traditions non institutionnelles doivent rester représentables ; provenance != adhésion.

L'engagement v9 existant porte sur le payload logique à `canon/domain/v9-logical-payload.json`. Les relations et structures déjà déclarées dans le corpus historique demeurent la référence détaillée. Le seul changement de layout ne crée pas de nouveaux prédicats ni de nouveaux IDs.
