# Kristal-Religion

**Kristal-Religion 1.0.0** est un corpus statique Kristal v6 centré sur la chaîne comparative :

**tradition → croyance → texte/transmission → pratique → institution → communauté**

La chaîne est un axe de navigation, pas une théorie universelle du développement religieux. Les traditions peuvent être fortement orales, peu institutionnalisées, décentralisées, non théistes, sans canon fermé ou sans catégorie équivalente à un clergé. Le corpus encode donc les interfaces, boucles de rétroaction et variations de structure comme objets de premier rang.

Le Kristal décrit les croyances comme des croyances situées : il n’affirme ni ne nie leur vérité métaphysique. Il privilégie une approche comparative, descriptive, multitraditionnelle et attentive à la diversité interne.

État canonique : `knowledge-base/corpus/religion.kristal-state.json`

Validation : `python knowledge-base/tools/validate.py`
