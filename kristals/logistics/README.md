# Kristal-Logistics v1.0.0

Kristal de référence sur les flux physiques de biens et d’unités logistiques.

**Chemin canonique :** `objet → origine → stockage → déplacement → destination`.

Axes transversaux : **demande/commande**, **contrôle/traçabilité** et **performance/contraintes**. Le flux inverse est explicitement modélisé.

- 189 référents
- 373 assertions atomiques
- 9 sources de référence
- 41 assertions avec références documentaires explicites

Le corpus est statique, validé et lisible sans réseau.
