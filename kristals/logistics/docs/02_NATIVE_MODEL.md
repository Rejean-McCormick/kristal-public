# Forme native — Kristal-Logistics

**Type de forme découvert :** `logistics_flow_network_with_reverse_flows`. Cette désignation est descriptive dans l'enveloppe d'authoring, elle ne remplace pas le contrat de l'artefact historique.

**Axes utiles :** objet, origine, stockage, déplacement, destination, retour.

**Invariant :** Les flux inverses, la demande, le contrôle, la traçabilité et les contraintes restent explicitement distingués.

Le payload logique historique est un **état portable v6** avec assertions atomiques, provenance, applicabilité et extensions de domaine. Il est engagé en v9 sous le contrat `kristal.compat/v6-portable-state-logical-projection/1.0`.

Les schémas métier sous `knowledge-base/` sont conservés ; aucun schéma graphique universel n'est imposé par la normalisation.
