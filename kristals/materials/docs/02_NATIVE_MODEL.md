# Forme native — Kristal-Materials

**Type de forme découvert :** `condition_scoped_material_property_graph`. Cette désignation est descriptive dans l'enveloppe d'authoring, elle ne remplace pas le contrat de l'artefact historique.

**Axes utiles :** composition, état/procédé, structure, propriété, comportement, mesure, environnement, usage.

**Invariant :** Une valeur de propriété dépend de l’état, de la méthode et des conditions de mesure ; candidat à un usage ≠ aptitude certifiée.

Le payload logique historique est un **état portable v6** avec assertions atomiques, provenance, applicabilité et extensions de domaine. Il est engagé en v9 sous le contrat `kristal.compat/v6-portable-state-logical-projection/1.0`.

Les schémas métier sous `knowledge-base/` sont conservés ; aucun schéma graphique universel n'est imposé par la normalisation.
