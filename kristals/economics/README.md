# Kristal Economics — allocation de ressources

Kristal Economics représente les mécanismes fondamentaux par lesquels des **agents sous contraintes** utilisent, produisent, échangent et allouent des ressources rares.

```text
AGENTS → CONTRAINTES → CHOIX / INCITATIONS
   ↓                         ↓
RESSOURCES → PRODUCTION → BIENS / SERVICES
   ↓                         ↓
TRANSACTIONS ↔ PRIX ↔ OFFRE / DEMANDE
   ↓
MÉCANISMES D’ALLOCATION → DISTRIBUTION DES RESSOURCES
```

Le marché est un mécanisme d’allocation parmi plusieurs. Le paquet encode explicitement les hypothèses des modèles afin de ne pas transformer un benchmark économique en loi universelle.

Standard cible : **Kristal 6.0**. Version : **1.0.0**.
