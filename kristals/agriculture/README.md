# Kristal-Agriculture

Kristal-Agriculture 1.0.0 is a static, source-backed Kristal v6 corpus for crop-production systems:

**soil → cultivated organism → inputs → practices → yield**

The sequence is a navigation axis, not a deterministic causal pipeline. Cross-stage interfaces are first-class referents.

Here, “biological production system” means a system built around living cultivated organisms; it does **not** mean certified organic agriculture.

Canonical state: `knowledge-base/corpus/agriculture.kristal-state.json`

Run `python knowledge-base/tools/validate.py` from the package root to validate schema, references, hashes, evidence coverage and manifest integrity.
