# Orientations et projections — Kristal-Craft

Orientation métier (historique) : **matière → outil → geste → opération → objet**.

Cette expression décrit le modèle de navigation déjà documenté, sans prétendre que les différents axes sont une ontologie universelle ou qu’une relation fléchée impose toujours la causalité.

Le portable v6 et les vues v8 continuent d’exister sous leurs chemins historiques. Aucune nouvelle projection ne remplace la structure métier actuelle.
