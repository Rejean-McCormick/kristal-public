# Offline source store — not canonical law

The files under `sources/DocVatican/` are the exact captures received in DocVatican.zip, not new official texts or reviewed editions. HTML/TXT physical hashes are recorded in `source-inventory.json`. Offline availability does not attest to the current legal applicability of a provision.

Important: the imported acquisition report declared one PDF as successful but the PDF bytes were absent from the supplied archive. It is NOT bundled and is NOT declared available.

Several pages of the CIC contain amended and earlier versions of the same canon within the same text file; see `validation/canon-collisions.json`. No version is automatically chosen for legal use.
