# Kristal Earth — paquet consolidé

Kristal Earth représente le **système Terre couplé** : géosphère, hydrosphère, atmosphère et biosphère, avec cryosphère transversale. Son unité de raisonnement opérationnelle est :

```text
SPHÈRE → RÉSERVOIR → STOCK
                 ↘ FLUX → PROCESSUS → RÉSERVOIR
                           ↘ CYCLE / BUDGET
                              ↘ ÉCHELLES
```

Le paquet cible Kristal Standard **6.0** et sépare état canonique, référents, sources éditoriales et projections dérivées.

Version : **1.0.0**.
