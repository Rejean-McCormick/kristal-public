# Frontière sémantique — Kristal-Software

Le modèle décrit : **intention → spécification → code → exécution → état → défaut**.

## Invariant

Intention ≠ exigence ≠ spécification ≠ code ≠ exécution ; défaut ≠ état erroné ≠ défaillance.

## Ownership

La vérité propre du Kristal est la connaissance locale engagée et qualifiée par les sources existantes. Le Kristal ne possède pas les sources externes ou leur politique de publication.
