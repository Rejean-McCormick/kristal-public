# Kristal Governance v1.0.0

Kristal v6 statique de référence sur la chaîne **mandat → institution → compétence → décision → mise en œuvre → reddition de comptes**.

## Noyau

`mandat → institution → compétence d’attribution → décision → mise en œuvre → résultats → reddition de comptes → rétroaction`

Le corpus distingue explicitement **la source de l’autorité**, **l’institution qui la porte**, **le champ dans lequel elle peut agir**, **la décision formelle**, **son exécution**, **les résultats observés** et **les mécanismes qui obligent les acteurs à expliquer, justifier et corriger leur action**.

## Garde-fous sémantiques principaux

- mandat ≠ autorité illimitée ;
- institution ≠ organisation ;
- compétence d’attribution ≠ compétence-savoir-faire ;
- autorité formelle ≠ pouvoir de fait ;
- délégation ≠ disparition automatique de la reddition de comptes ;
- discrétion ≠ arbitraire ;
- décision ≠ mise en œuvre ;
- mise en œuvre ≠ résultat ;
- produit ≠ résultat ≠ impact ;
- indicateur ≠ objectif ;
- conformité ≠ efficacité ;
- consultation ≠ consentement ;
- participation ≠ autorité décisionnelle ;
- consensus ≠ unanimité ;
- conflit d’intérêts ≠ faute établie ;
- reddition de comptes ≠ simple rapportage ;
- transparence ≠ divulgation absolue ;
- surveillance ≠ gestion ;
- audit ≠ évaluation ;
- légalité ≠ légitimité ≠ efficacité.

## Frontière

Inclus : gouvernance générale, mandat, institution, rôles, compétence d’attribution, délégation, décision, participation, conflits d’intérêts, mise en œuvre, suivi, résultats, transparence, contrôle, audit, évaluation, recours et rétroaction institutionnelle.

Exclus : droit constitutionnel propre à une juridiction, règles électorales, recommandations partisanes, contentieux administratif détaillé, finances publiques approfondies et politiques sectorielles particulières.

## Contenu

- `corpus/governance.kristal-state.json` — état canonique v6
- `corpus/referents.json` — registre conceptuel FR/EN
- `sources/` — catalogue et registre d’évidence
- `profiles/` — profil de navigation
- `documentation/` — architecture, frontière et garde-fous
- `tools/validate.py` — validation locale

Les sources externes établissent la provenance des assertions; leur contenu n’est pas incorporé textuellement dans le corpus. Ce Kristal ne détermine pas la validité juridique d’un acte dans une juridiction particulière.
