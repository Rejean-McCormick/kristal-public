# Modèle épistémique — Kristal-Chemistry

## Preuves et sources

La bibliographie / provenance historique est accessible dans `.kristal/v9/logical-artifact.json#payload.source_refs`. Sa vue normalisée est `sources/source-catalog.json` (32 entrées). Les métadonnées complètes et politiques historiques demeurent dans le fichier d'origine ou dans le payload engagé.

## Interprétation

Une source, une assertion, un auteur et un engagement logique ont des fonctions distinctes : provenance ≠ autorité ≠ vérité. Un désaccord ne doit pas être résolu sans justifier l'autorité. `unknown` ≠ `false`.

Invariant disciplinaire : identité ≠ classification ; réaction chimique ≠ transition de phase ; propriété ≠ observation et les réactions n’imposent pas un DAG.

Une réponse d'IA reste une proposition. Un index de requête ou une projection peut montrer une information sans devenir une source d'autorité.
