# Épistémologie et autorité — Kristal-Logic

Le Kristal conserve les `source_refs`, la provenance et les statuts épistémiques exactement comme dans le corpus d'origine. Une référence source n'est pas automatiquement une preuve ni une autorité unique.

Les divergences de sources doivent rester explicites et ne pas être remplacées silencieusement par un résumé. Les sorties IA ne sont pas promues en faits par défaut.

Le catalogue normalisé `sources/source-catalog.json` comprend 8 références, dont 0 notices avec identifiant seul. Ces notices incomplètes ne constituent pas une vérification externe des sources.

Vérité ≠ validité ; ⊢ ≠ ⊨ ; implication matérielle ≠ conséquence logique ; les règles classiques ne valent pas automatiquement pour les systèmes non classiques.
