# Repères de domaine — Kristal-Logic

- **Subject :** Formes de propositions, règles d’inférence, modèles, validité et preuves logiques
- **Modèle natif :** typed_formal_syntax_semantics_proof_graph
- **Axes :** syntaxe, sémantique, métalogique, preuves, contre-modèles
- **Distinction impérative :** Vérité ≠ validité ; ⊢ ≠ ⊨ ; implication matérielle ≠ conséquence logique ; les règles classiques ne valent pas automatiquement pour les systèmes non classiques.
