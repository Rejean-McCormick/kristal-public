# Forme native — Kristal-Logic

**Type de forme découvert :** `typed_formal_syntax_semantics_proof_graph`. Cette désignation est descriptive dans l'enveloppe d'authoring, elle ne remplace pas le contrat de l'artefact historique.

**Axes utiles :** syntaxe, sémantique, métalogique, preuves, contre-modèles.

**Invariant :** Vérité ≠ validité ; ⊢ ≠ ⊨ ; implication matérielle ≠ conséquence logique ; les règles classiques ne valent pas automatiquement pour les systèmes non classiques.

Le payload logique historique est un **état portable v6** avec assertions atomiques, provenance, applicabilité et extensions de domaine. Il est engagé en v9 sous le contrat `kristal.compat/v6-portable-state-logical-projection/1.0`.

Les schémas métier sous `knowledge-base/` sont conservés ; aucun schéma graphique universel n'est imposé par la normalisation.
