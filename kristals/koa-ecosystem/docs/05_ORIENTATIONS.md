# Orientations and projections

The project already contains many derived views (`views/`) that orient the same canonical graph by repository, capability, operating function, utility, workflow, support boundary and other concerns. Those legacy views are not canonical.

No Local Kit portable projection recipe is registered during this normalization. If one is later added under `projections/recipes/`, it must preserve the Local Kit rule of exactly one primary orientation axis and at most one secondary orientation axis.

Adding or regenerating a projection must not change the canonical graph or its Logical Commitment.
