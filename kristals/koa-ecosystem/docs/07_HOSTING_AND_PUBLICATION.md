# Hosting and publication

This normalization does **not** configure a hosted-network target and does not publish or activate anything. Repository URLs present in the domain/source catalogs are evidence and locators; they are not Local Kristal hosting configuration.

Responsibilities remain separated:

- Local Kit: structure, check and build-v9.
- Kristal Manager: inventory and backup of the full local folder.
- Kristal GitHub Setup / Bootstrap: exact-commit qualification, network publication and activation when explicitly requested.
- Kompiler / portable AI: optional derived reading layer only.

Backup visibility, Git branch, URL, repository location and read-model generation do not alter the State Logical Commitment. Publication and activation must be explicit operations.
