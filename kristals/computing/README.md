# Kristal-Computing

**Édition 1.0.0 — Kristal v6 natif**

Kristal-Computing décrit le computing comme **transformation d’information** plutôt que comme catalogue de logiciels ou de produits.

## Thèse de domaine

```text
information
   ↓ représentation
représentation manipulable
   ↓ calcul ↔ stockage
état transformé et conservé
   ↓ communication
échange entre systèmes
   ↓ abstraction
contrats stables au-dessus d'implémentations variables
```

Les cinq axes canoniques sont : **représentation, calcul, stockage, communication, abstraction**.

## Contenu

- `corpus/computing.kristal-state.json` — état canonique v6;
- `corpus/referents.json` — vocabulaire bilingue FR/EN;
- `corpus/invariants.json` — distinctions non négociables du domaine;
- `corpus/navigation.json` — points d'entrée et hubs inter-axes;
- `corpus/boundaries.json` — frontières avec Math, Physique, Security, AI et produits logiciels;
- `sources/source-catalog.json` — sources primaires/consensuelles;
- `validation/validation-report.json` — validation structurelle et référentielle;
- `manifest.sha256.json` — intégrité de tous les fichiers de l'édition.

## Politique éditoriale

Le noyau est volontairement **statique et fondamental**. Les technologies particulières n'entrent que lorsqu'elles servent de normes d'interface durables (Unicode, RFC Internet, ISA ouverte) et non comme objets de veille. Les assertions restent atomiques et traçables.

## Frontière

Ce Kristal ne tente pas de devenir Math, Physics/Electronics, Security ou AI. Il conserve uniquement les concepts d'interface nécessaires pour décrire comment l'information est représentée, transformée, conservée, transmise et abstraite.
