# Orientations — Kristal-Internet

L'orientation est dérivée de la forme native `protocol-addressing-routing-service-dependency-model` et des documents existants. Les rôles canoniques sont :

- `semantic_model`
- `identifier_model`
- `layer_model`
- `addressing_model`
- `protocol_model`
- `service_model`
- `routing_model`
- `security_model`
- `failure_model`
- `relation_model`
- `semantic_invariants`
- `source_catalog`

Aucune projection nouvelle n'est inventée. Les projections héritées sous `knowledge-base/corpus/` et `.kristal/v8` restent consultables. Les axes d'affichage n'altèrent pas le Logical Commitment.
