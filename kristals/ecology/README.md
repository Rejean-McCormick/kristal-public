# Kristal Ecology v1.0.0

Corpus statique de référence consacré aux **réseaux d’interactions vivantes** : organisme ↔ population ↔ communauté ↔ écosystème, avec flux de matière et d’énergie.

Le Kristal est volontairement **non taxonomique**. Il décrit les relations, processus, modèles et contraintes écologiques plutôt qu’un inventaire d’espèces.

Canonical artifact: `knowledge-base/corpus/ecology.kristal-state.json` (Kristal Standard 6.0).

Validation: `python knowledge-base/tools/validate.py`.
Query: `python knowledge-base/tools/query.py --topic trophic_networks`.
