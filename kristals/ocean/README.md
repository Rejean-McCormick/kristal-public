# Kristal Ocean v1.0.0

Corpus statique de référence consacré aux **masses d’eau et aux flux océaniques** : profondeur, température, salinité, densité, circulation, chimie, biogéochimie et grands habitats.

Le Kristal traite l’océan comme un **système physique-chimique-biologique couplé**. Il décrit les milieux et contraintes des écosystèmes sans dupliquer les réseaux d’interactions détaillés de Kristal Ecology.

Canonical artifact: `knowledge-base/corpus/ocean.kristal-state.json` (Kristal Standard 6.0).

Validation: `python knowledge-base/tools/validate.py --write-report`.
Query: `python knowledge-base/tools/query.py --topic circulation_wind`.
