# Kristal-PiTheory v0.2.0

**Pi Theory — structure locale, méthode de décodage et lecture ontologique des 36 premiers chiffres de π**

Kristal de travail organisé autour de sept axes :

`mécanique → structure → ontologie → épistémologie → résonances → histoire → validation`

La flèche est une **projection de navigation**, pas une preuve de causalité physique. L’état canonique est `knowledge-base/corpus/pi-theory.kristal-state.json`; `.kristal/v8/` est une projection dérivée/reconstruisible.

Lecture de travail :
