# Orientations et projections

**Orientation métier existante :** objectif → rôle → unité → processus → décision → résultat (orientation, pas causalité universelle).

La projection portable v6/v7 (si présente) est un read model de compatibilité. Les index v8 et les vues de recherche sont distincts de la connaissance logique, et ne doivent pas être dupliqués comme membres v9. Les axes secondaires dépendent du modèle natif et des profils existants. Aucune projection nouvelle n'est inventée ici.
