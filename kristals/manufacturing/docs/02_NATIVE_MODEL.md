# Forme native — Kristal-Manufacturing

**Type de forme découvert :** `traceable_process_measurement_dag`. Cette désignation est descriptive dans l'enveloppe d'authoring, elle ne remplace pas le contrat de l'artefact historique.

**Axes utiles :** matière, procédé, géométrie, tolérance, métrologie, qualité, traçabilité.

**Invariant :** Géométrie nominale ≠ géométrie réelle ≠ résultat de mesure ; tolérance ≠ incertitude ; non-conformité ≠ défaut ≠ aptitude à l’usage.

Le payload logique historique est un **état portable v6** avec assertions atomiques, provenance, applicabilité et extensions de domaine. Il est engagé en v9 sous le contrat `kristal.compat/v6-portable-state-logical-projection/1.0`.

Les schémas métier sous `knowledge-base/` sont conservés ; aucun schéma graphique universel n'est imposé par la normalisation.
