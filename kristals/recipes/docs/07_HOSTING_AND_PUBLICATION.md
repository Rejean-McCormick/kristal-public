# Hosting, publication et activation v10

La présente migration ne configure pas de repository hôte, de branche, de Framework SHA ni de canal d’activation. Le State Commitment v9 reste `sha256:5318163afb08353c04e72112999d91e8b48d97e5f527235e932a603b85fd33c4`.
