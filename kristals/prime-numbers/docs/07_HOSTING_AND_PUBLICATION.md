# Hosting, publication et activation v10

La présente migration ne configure pas de repository hôte, de branche, de Framework SHA ni de canal d’activation. Le State Commitment v9 reste `sha256:ec0c647012acf3906009f33ce5d4cf86fc6bc2848be1b7d36d87aa511a688c91`.

Le lifecycle normal reste **build → qualification → publication (commit exact) → activation (optionnelle)**. Une archive locale normalisée n'est ni un artefact publié sur GitHub, ni une activation.
