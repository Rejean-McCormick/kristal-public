# Kristal-HCI v1.0.0

Kristal de référence sur l’interaction humain-système.

**Chemin canonique :** `utilisateur → objectif → interface → interaction → feedback → résultat`.

Axes transversaux : **contexte d’usage** et **évaluation**. L’accessibilité traverse l’ensemble du modèle.

- 146 référents
- 286 assertions atomiques
- 9 sources de référence
- 74 assertions avec références documentaires explicites

Le corpus est statique, validé et lisible sans réseau.
