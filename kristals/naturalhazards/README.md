# Kristal-NaturalHazards

Kristal-NaturalHazards 1.0.0 is a static, source-backed Kristal v6 corpus centered on:

**hazard × exposure × vulnerability → risk**

The multiplication sign is conceptual: risk emerges from interaction among determinants and is not defined here as a universal numeric product. Capacity, resilience, uncertainty, multi-hazard interactions and risk-reduction measures are represented as cross-cutting concepts.

The corpus covers major natural-hazard families and a sparse set of meaningful hazard→exposure and exposure→vulnerability relations. It is not a real-time warning system and does not contain local evacuation orders.

Canonical state: `knowledge-base/corpus/naturalhazards.kristal-state.json`

Run `python knowledge-base/tools/validate.py` from the package root to validate schema, references, hashes, evidence coverage and manifest integrity.
