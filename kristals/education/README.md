# Kristal-Education v1.0.0

Corpus statique et validé décrivant la grammaire **apprenant → objectif → activité → évaluation → progression**.

## Noyau conceptuel

- **Apprenant** : état daté, connaissances antérieures, besoins, engagement, autorégulation et accessibilité.
- **Objectif** : acquis visé, compétence, connaissance, habileté, prérequis, critères et alignement.
- **Activité** : enseignement, pratique, problème, projet, simulation, collaboration, étayage et ressources.
- **Évaluation** : finalité, tâche, preuve, score, interprétation, validité, fidélité, équité et rétroaction.
- **Progression** : maîtrise, croissance, rétention, transfert, remédiation, avancement et prochaine étape.

## Invariant central

Une observation, un score ou une note n'est pas l'apprentissage lui-même. Le Kristal représente la progression comme une **estimation révisable de l'état d'apprentissage**, relative à des objectifs explicites et soutenue par des preuves dont l'interprétation possède ses propres limites.

## Garde-fous majeurs

- activité ≠ objectif ;
- tâche d'évaluation ≠ objectif ;
- preuve ≠ maîtrise ;
- score ≠ compétence ;
- note ≠ état complet de l'apprenant ;
- fidélité ≠ validité ;
- formative ≠ simple quiz sans note ;
- croissance ≠ maîtrise ;
- rétention ≠ transfert ;
- préférence déclarée ≠ règle d'efficacité pédagogique ;
- trace numérique ≠ preuve d'apprentissage automatique ;
- état d'apprentissage ≠ trait fixe d'aptitude.
