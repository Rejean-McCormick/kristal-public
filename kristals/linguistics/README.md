# Kristal-Linguistics

Kristal-Linguistics 1.0.0 is a static, source-backed Kristal v6 corpus for the structural levels of human language:

**phonology → morphology → syntax → semantics → pragmatics**

The sequence is a navigation axis, not a claim that grammar or processing is a rigid pipeline. Interfaces are first-class referents.

Canonical state: `knowledge-base/corpus/linguistics.kristal-state.json`

Run `python knowledge-base/tools/validate.py` from the package root to validate schema, references, hashes, evidence coverage and manifest integrity.
