# Épistémologie et autorité — Kristal-Linguistics

Le Kristal conserve les `source_refs`, la provenance et les statuts épistémiques exactement comme dans le corpus d'origine. Une référence source n'est pas automatiquement une preuve ni une autorité unique.

Les divergences de sources doivent rester explicites et ne pas être remplacées silencieusement par un résumé. Les sorties IA ne sont pas promues en faits par défaut.

Le catalogue normalisé `sources/source-catalog.json` comprend 10 références, dont 0 notices avec identifiant seul. Ces notices incomplètes ne constituent pas une vérification externe des sources.

Les interfaces entre niveaux sont des objets de première classe ; leur ordre de lecture ne constitue pas une chaîne de traitement universelle.
