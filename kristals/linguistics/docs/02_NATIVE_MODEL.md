# Forme native — Kristal-Linguistics

**Type de forme découvert :** `layered_linguistic_relational_graph`. Cette désignation est descriptive dans l'enveloppe d'authoring, elle ne remplace pas le contrat de l'artefact historique.

**Axes utiles :** phonologie, morphologie, syntaxe, sémantique, pragmatique.

**Invariant :** Les interfaces entre niveaux sont des objets de première classe ; leur ordre de lecture ne constitue pas une chaîne de traitement universelle.

Le payload logique historique est un **état portable v6** avec assertions atomiques, provenance, applicabilité et extensions de domaine. Il est engagé en v9 sous le contrat `kristal.compat/v6-portable-state-logical-projection/1.0`.

Les schémas métier sous `knowledge-base/` sont conservés ; aucun schéma graphique universel n'est imposé par la normalisation.
