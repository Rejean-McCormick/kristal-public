## Garde-fous conceptuels

La confiance kOA n'est pas une réserve monétaire. K_M et K_C sont distincts.
Une prime artistique n'est pas une valeur de garantie automatique. Le droit
coopératif, la solvabilité, les droits individuels et les contraintes fiscales
restent applicables. Une amélioration de gouvernance ne rembourse pas de dette
sans gains nets et financement. Les résultats simulés ne sont pas des preuves.

**Ce projet ne représente pas une autorisation de Desjardins, une licence
monétaire, un partenariat institutionnel, une qualification indépendante, ni
une approbation de l'économie modélisée.**
