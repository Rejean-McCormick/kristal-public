# Frontière sémantique

Propriété : État atmosphérique, forçages, structures, observation, analyse, prévision et risques.

Invariant métier préservé : Observation ≠ analyse ≠ prévision ; météo ≠ climat ; aléa ≠ impact.

L’autorité des références externes reste celle des artefacts historiques ; aucun ownership des données externes ni des autres Kristals n’est créé.
