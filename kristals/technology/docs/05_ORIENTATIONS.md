# Orientations et projections — Kristal-Technology

Axe métier : **besoin → fonction → principe → composant → système → usage → défaillance**.

Fonction ≠ solution ; principe ≠ composant ; usage ≠ identité de système ; le modèle décrit des archétypes, pas des produits OEM.

Une orientation sert à lire/interroger le domaine ; elle ne crée ni causalité, ni équivalence, ni preuve nouvelles. Les projections v6/v8 historiques sont préservées et aucune orientation artificielle n’est ajoutée.
